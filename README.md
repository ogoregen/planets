
Simple 3D gravitational attraction simulation

- **Mouse Controls:**
  - Hold down and release the left mouse button to launch a new planet with an initial velocity.
  - Use the mouse scroll wheel to change the size of the planet being created.
  - Drag the mouse to rotate the 3D view and explore different angles.

- **Keyboard Controls:**
  - Use Q/E keys to adjust the Z-depth for planet creation (closer/farther in 3D space).

- **UI Controls:**
  - Use the slider to alter the time scale of the simulation.
  - Use the mouse scroll wheel to scale the view when not creating a planet.

## Dependencies

- [p5.js](https://p5js.org/)
